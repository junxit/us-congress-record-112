# MEASURE READ THE FIRST TIME--S. 3664

```
                  MEASURE READ THE FIRST TIME--S. 3664

  Mrs. HAGAN. Mr. President, I understand that S. 3664, introduced 
earlier today by Senator Reid, is at the desk, and I ask for its first 
reading.
  The PRESIDING OFFICER. The clerk will read the bill by title.
  The legislative clerk read as follows:

       A bill (S. 3664) to provide for debt limit extensions.

  Mrs. HAGAN. Mr. President, I now ask for its second reading and 
object to my own request.
  The PRESIDING OFFICER. Objection having been heard, the bill will be 
read for a second time on the next legislative day.

                          ____________________
```
