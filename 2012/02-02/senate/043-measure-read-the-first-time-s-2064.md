# MEASURE READ THE FIRST TIME--S. 2064

```
                  MEASURE READ THE FIRST TIME--S. 2064

  Mr. REID. I now ask that we have the first reading of a bill which is 
at the desk.
  The PRESIDING OFFICER. The clerk will read the bill by title for the 
first time.
  The assistant legislative clerk read as follows:

       A bill (S. 2064) to amend the Internal Revenue Code of 1986 
     to terminate certain energy tax subsidies and lower the 
     corporate income tax rate.

  Mr. REID. I ask for a second reading in order to place this bill on 
the calendar, but I object to my own request.
  The PRESIDING OFFICER. Objection is heard. The bill will be read for 
the second time on the next legislative day.

                          ____________________
```
