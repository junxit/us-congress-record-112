# MEASURE READ THE FIRST TIME--S. 3576

```
                  MEASURE READ THE FIRST TIME--S. 3576

  Mr. REID. Mr. President, I understand S. 3576, introduced earlier 
today by Senator Paul, is at the desk. I believe it is due for its 
first reading.
  The PRESIDING OFFICER. The clerk will read the bill by title for the 
first time.
  The legislative clerk read as follows:

       A bill (S. 3576) to provide limitations on United States 
     assistance, and for other purposes.

  Mr. REID. Mr. President, I now ask for a second reading but object to 
my own request.
  The PRESIDING OFFICER. Objection is heard. The bill will be read for 
the second time on the next legislative day.
```
