# ORDER OF PROCEDURE

```
                           ORDER OF PROCEDURE

  Mr. REID. Senator Schumer and Senator Alexander are that far from an 
agreement that we can move forward on the next bill. So with everyone's 
patience, I ask unanimous consent that the cloture vote scheduled to 
occur immediately--right now--be postponed until Wednesday; that is 
tomorrow, June 22, at a time to be determined by the majority leader, 
in consultation with the Republican leader, and that if cloture is 
invoked tomorrow, time postcloture be counted as if cloture was invoked 
at 6 p.m. today.
  The PRESIDING OFFICER. Is there objection?
  Without objection, it is so ordered.

                          ____________________
```
